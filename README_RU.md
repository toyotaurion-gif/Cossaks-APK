# Казаки 1.52 — Android-клиент установщик (исходный проект)

**Статус:** исходный проект Android Studio, не готовый APK. В текущем окружении отсутствует Android SDK, поэтому сборка и реальное выполнение на телефоне здесь не проверены.

## Сборка

* Откройте папку в Android Studio и выберите Build > Build APK(s), или загрузите её в свой GitHub-репозиторий (содержит GitHub Actions workflow `Build Android APK`).
* Debug APK появится в `app/build/outputs/apk/debug/app-debug.apk`.
* Если ставите рядом со старым APK с другой подписью, Android потребует удалить старую версию. Перед удалением проверьте сохранения и данные игры.

## Логика клиента

1. Первый запуск: предлагает загрузить полный веб-архив и спрашивает согласие.
2. Android-проводник просит выбрать папку, куда поместить ресурсы. SAF URI сохраняется в `SharedPreferences` с persistent access.
3. Скачивает архив по прямой HTTPS-ссылке, указанной в README исходного GitHub проекта `MisterCoderman/cossacks-1.52-platform`. Файлы по ссылке фактически расположены на Archive.org.
4. Распаковывает игровой архив в выбранную папку, проверяет `dmcr.js` и `dmcr.wasm`. Перед заменой `dmcr.html` делает `dmcr.html.backup`.
5. Использует наш модифицированный `dmcr.html` из assets с мышиным управлением и DEL только по двойному тапу.
6. Далее повторно запускает игру без скачивания. Поддерживает обновление только управляющего HTML и импорт полного ZIP с телефона.

**Важно:** GitHub-архив исходного кода — не игровой пакет. Для настоящего запуска нужен полный `Cossacks152-Web-SinglePlayer.zip` с ресурсами. Он может занимать более 1 ГБ после распаковки; требуется свободная память. Игровая логика 18-го века и шахт находится в `dmcr.wasm`, здесь не исправлялась. WebView/WebAssembly, звук, сохранения и фактический запуск требуют проверки на устройстве.

## Существующие ограничения / перед релизом

* Пакет не тестировался на Android в этом окружении.
* Для полной отказоустойчивости крупных обновлений понадобится транзакционная установка игровых данных, а также проверка SHA-256 полного архива, когда автор опубликует контрольную сумму.
* Этот клиент однопользовательский; сетевой multiplayer требует отдельного сервера.

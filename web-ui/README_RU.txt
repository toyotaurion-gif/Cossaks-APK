КОЗАКИ — DEL ДВОЙНОЙ ТАП v0.8.4

ВНИМАНИЕ: ZIP НЕ УСТАНАВЛИВАЕТСЯ КАК APK И НЕ ОБНОВЛЯЕТ ИГРУ АВТОМАТИЧЕСКИ.

1. ПОЛНОСТЬЮ ЗАКРОЙТЕ игру.
2. Откройте архив и извлеките файл dmcr.html.
3. Найдите в памяти папку игры, где уже есть dmcr.js и dmcr.wasm.
4. В этой папке переименуйте прежний dmcr.html в dmcr.backup.html (резервная копия).
5. Поместите туда НОВЫЙ dmcr.html из архива. Имя должно быть в точности dmcr.html — не dmcr(1).html и не dmcr-v0.8.4.html.
6. Запустите игру заново. НА КНОПКЕ ДОЛЖНО БЫТЬ «DEL ×2» КРУПНО, ЖЁЛТЫМИ БУКВАМИ. Если эта надпись не появилась, игра загружает ДРУГУЮ копию dmcr.html либо использует встроенный файл из APK.

Режим: два кратких тапа в пределах 550 мс, срабатывание только при отпускании пальца на втором тапе. Одиночное касание, удержание, смахивание ничего не удаляют.

ЕСЛИ ИГРА УСТАНОВЛЕНА APK:
Встроенный dmcr.html нельзя заменить скачиванием ZIP. Нужен новый собранный APK либо кнопка «Обновить управление» в v0.9.x Android-клиенте (если он действительно установлен и собран).

Остальное управление, исходный движок и игровые данные не изменены.

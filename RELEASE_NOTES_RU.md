# Казаки 1.52 для Android — тестовый автоустановщик

**Что нового:** пользователь скачивает только один APK. При первом запуске приложение автоматически загружает веб-версию «Казаков: Снова война» 1.52, распаковывает файлы, добавляет сенсорное управление и открывает игру. Ручной выбор ZIP и папки не нужен. В дальнейшем ресурсы хранятся локально.

**ВНИМАНИЕ — тестовая сборка:** работоспособность на реальных Android-устройствах пока не подтверждена. Для первого запуска нужен интернет и около 3–4 ГБ свободной памяти. Игра загружается с внешнего ресурса, не включённого в APK, и её доступность зависит от владельца источника. Код установщика открыт в репозитории; права на исходную игру сохраняются у соответствующих владельцев.

**Как использовать:** установите APK → откройте «Казаки 1.52» → дождитесь загрузки → игра начнётся автоматически, если установка завершится успешно. Если возникла ошибка, выберите «Повторить загрузку».

**Подпись:** тестовая сборка подписывается временным debug-ключом GitHub Actions. Для будущих обновлений поверх предыдущих сборок необходим постоянный ключ подписи. Для массового распространения эту сборку использовать не следует.
